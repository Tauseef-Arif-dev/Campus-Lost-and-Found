# Campus Lost and Found Management System

## Project Overview
Campus Lost and Found is a web-based application designed to help university students report and find lost or misplaced items on campus.

The system provides a simple platform where students can submit lost or found item reports and browse available reports.

## Features
- Report Lost Items
- Report Found Items
- Browse All Reports
- Search Items
- Filter Lost and Found Reports
- Mark Items as Resolved
- Reopen Resolved Reports
- Delete Reports
- Dashboard Statistics
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Files
- `index.html` – Main structure of the website.
- `style.css` – Website design and styling.
- `script.js` – Application functionality.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start using the Campus Lost and Found application.
